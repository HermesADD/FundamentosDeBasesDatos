Especificaciones del programa.

Desarrollar un prototipo que solicite información y la almacene en archivos .cvs. 

La farmacia necesita almacenar
- Sucursales
- Medicamentos
- Clientes

Se debe permitir agregar, consultar, editar, y eliminar información de sucursales, medicamentos, clientes. Se debe guardar y leer la información en archivos .cvs.

Se necesita un menú de interacción. 

Es necesario que la aplicación reciba la llave de la identidad y nos regrese todos los datos relacionados con esta.
